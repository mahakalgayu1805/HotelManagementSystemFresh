# Hotel Management System

A professional web-based Hotel Management System developed using **ASP.NET Core Razor Pages, C#, Entity Framework Core and SQL Server**.

The system helps hotel administrators manage rooms, customers, bookings, room availability and booking billing from a centralized dashboard.

## Features

* Professional Admin Dashboard
* Room Management
* Customer Management
* Booking Management
* Add, Edit, View and Delete operations
* Room availability management
* Booking status management
* Check-In and Check-Out tracking
* Booking date validation
* Duplicate booking prevention
* Automatic number of nights calculation
* Automatic total bill calculation
* Search and filter functionality
* Occupancy calculation
* Revenue calculation
* Recent bookings dashboard
* Responsive and professional user interface

## Modules

### Dashboard

The dashboard provides an overview of hotel operations including:

* Total Rooms
* Available Rooms
* Occupied Rooms
* Total Customers
* Total Bookings
* Active Bookings
* Total Revenue
* Occupancy Rate
* Booking Status
* Recent Bookings
